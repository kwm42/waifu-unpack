# waifu-unpack 文档目录

把二次元手游 Unity AssetBundle 解开，导出为**可被现成工具直接预览**的原生模型格式：
Spine（`.skel` + `.atlas` + `.png`）、Live2D（`moc3 + model3.json + textures`）、静态立绘切片（PNG）。

- [README.md](./README.md) — 项目总览与快速上手
- [architecture.md](./architecture.md) — 代码分层、核心抽象、如何新增游戏
- [game-research.md](./game-research.md) — 各游戏资源格式研究结论与已知坑
- [conventions.md](./conventions.md) — 输出结构、命名规则、增量语义、决策记录
